# BookLeaf Author Support & Communication Portal

## Overview
A full-stack portal for authors to view book and royalty information and submit support tickets, plus an admin workspace for ticket triage and AI-assisted replies.

## Features
- Email/password login with author/admin roles
- Seeded BookLeaf author and book data
- Author books and royalty dashboard
- Ticket creation and ticket history
- Admin ticket queue, filters, priority and category overrides
- Assignment, status management, internal notes, public replies
- LLM-based classification, priority scoring, and response drafting when configured
- Manual fallback when the LLM is unavailable
- Polling to show ticket updates without manual refresh

## Setup
1. Clone the private repository.
2. Copy `server/.env.example` to `server/.env`.
3. Fill in database URI, JWT secret, admin credentials, and optional LLM key.
4. Copy `client/.env.example` to `client/.env` and set the API base URL.
5. Install dependencies in `server/` and `client/`.
6. Run the seed command once.
7. Start the API and client in separate terminals.
8. Open the client URL shown by Vite.
