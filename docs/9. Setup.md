# Local Setup Guide

This guide is a target setup plan. Update commands if the actual generated project differs.

## Prerequisites
- Node.js LTS and npm
- Git
- MongoDB Atlas database or local MongoDB
- VS Code
- Optional provider API key

Check:
```bash
node -v
npm -v
git --version
```

## Suggested environment variables

### `server/.env.example`
```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://127.0.0.1:27017/bookleaf_portal
JWT_SECRET=replace_with_a_long_random_secret
CLIENT_ORIGIN=http://localhost:5173
ADMIN_NAME=BookLeaf Admin
ADMIN_EMAIL=admin@bookleaf.demo
ADMIN_PASSWORD=change-this-demo-password
DEMO_AUTHOR_PASSWORD=change-this-demo-password
LLM_PROVIDER=mock
LLM_API_KEY=
LLM_MODEL=
```

Use the real provider's required environment variable name if the implementation uses a provider-specific SDK. Do not commit `.env`.

### `client/.env.example`
```env
VITE_API_BASE_URL=http://localhost:5000/api
```

Only `VITE_` values are exposed to browser code. Never put an LLM API key or JWT signing secret in the client environment.

## Install and run
From the repository root, use separate terminals.

Server:
```bash
cd server
npm install
npm run seed
npm run dev
```

Client:
```bash
cd client
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Verify
- `GET http://localhost:5000/api/health` returns a healthy status.
- Sign in with seeded author credentials.
- Sign in with admin credentials.
- Confirm books and royalties load.
- Create a ticket as an author.
- Respond as admin and confirm the author sees the response.

## MongoDB Atlas
- Create a database and database user.
- Restrict network access as appropriate; avoid broad permanent access rules.
- Copy the connection string to `MONGODB_URI`.
- URL-encode special characters in database passwords.
- Never commit the connection string.

## LLM provider
- If no key is available, set `LLM_PROVIDER=mock` and make sure UI clearly labels mock/degraded output.
- When a key is available, set the provider and model using server environment variables.
- Restart the server after changing environment variables.
- Confirm AI requests are sent only from the server.

## Common setup problems
- `node` not found: install Node.js LTS and restart terminal.
- Port busy: change `PORT` or stop the process using that port.
- Database connection failed: check URI, credentials, network allowlist, and database service.
- CORS error: ensure `CLIENT_ORIGIN` exactly matches the client origin.
- Client cannot call API: check `VITE_API_BASE_URL` and backend health endpoint.
- Login fails after reseeding: confirm the demo password configured at seed time.
